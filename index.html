About me

My QA workflow

The same six steps on every project.

  1. 1UnderstandApplication, requirements, business flow and user behavior.
  2. 2PlanScope, risks, scenarios and priorities.
  3. 3TestFunctional, regression, integration, UI, API and database testing.
  4. 4ReportClear steps, expected and actual results, supporting information.
  5. 5RetestFixed defects, then regression testing.
  6. 6DeliverA testing summary showing the quality status.
